오답노트가 늘어나면 (확장 방법)

  1. 이 HTML을 편집기로 열어 const DATA = [ 배열을 찾습니다.
  2. 기존 테마에 해당하면 그 테마의 srcs 배열에 한 줄만 추가하면 됩니다. 그러면 오답 횟수·반복 배지·대시보드가 자동 갱신됩니다.
  3. 새 개념이면 아래 형태로 객체를 추가합니다. 필드는 전부 선택 항목이며, 없으면 해당 블록이 렌더링되지 않습니다.
{ area:"데이터베이스", title:"새 개념 제목",
  srcs:[{q:"3-45", d:"0808", mine:"2", ans:"4"}],
  core:"핵심 한 줄",
  dia:"flowchart LR\n A --> B",            // Mermaid 소스 (선택)
  tables:[{cap:"표 제목", head:["구분","설명"], rows:[["A","..."]]}],
  mnemo:[{k:"두문자", v:"풀이"}],
  trap:"함정 포인트",
  quiz:[{q:"질문", a:"답"}] }

주의 — 문항번호는 회차마다 중복됩니다(예: 2-25, 4-61, 4-68은 두 회차에 모두 존재하나 내용이 다름). 반드시 d(시험일)를 함께 넣어야 충돌하지 않습니다.

새 회차의 과목별 오답 수는 const EXAMS = [ 배열에 {d:"0808", by:[6,4,5,8,7]} 형식으로 추가하면 대시보드에 반영됩니다. 순서는 소프트웨어설계·소프트웨어개발·데이터베이스구축·프로그래밍언어활용·정보시스템구축관리입니다.
