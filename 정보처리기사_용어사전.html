과목

챕터

헷갈리는 용어를 짝으로 잡는 사전

출제기준의 세세항목을 그대로 챕터로 삼아 필기 5과목 전 범위를 덮었습니다. 용어를 클릭하면 상세 설명 · 혼동 용어 · 출제 형태가 열립니다.

혼동 용어 칩을 누르면 그 용어로 즉시 이동해 나란히 비교할 수 있습니다. 시험이 서로 바꿔 내는 짝을 양방향으로 연결해 두었습니다.

왼쪽 ❓ 버튼으로 모르는 용어를 표시하고, 상단 모름만으로 그것만 모아 볼 수 있습니다. 표시는 브라우저에 저장됩니다.

/ 검색Esc 검색 해제클릭 펼치기❓ 모름 표시

구성 원칙

  • 챕터는 한국산업인력공단 출제기준의 주요항목 → 세부항목 → 세세항목 체계를 따릅니다. 세세항목에 없는 내용은 넣지 않았고, 있는 항목은 비우지 않았습니다.
  • 용어마다 혼동 용어를 붙였습니다. 시험은 개별 지식보다 비슷한 용어를 서로 바꿔치기해서 냅니다. 한 용어를 볼 때 반드시 짝을 함께 보세요.
  • 출제 형태는 그 용어가 실제로 어떤 문장 모양으로 출제되는지, 어디서 함정을 파는지 적었습니다.

확장 방법

파일을 편집기로 열어 const DICT = [ 를 찾으면 챕터 배열이 있습니다. 용어는 배열 6칸 구조입니다.

[ "용어명", "영문 / 풀네임", "한 줄 정의", "상세 설명", "혼동용어1|혼동용어2", "출제 형태" ]

혼동 용어는 다른 용어의 이름과 정확히 일치해야 링크가 걸립니다. 이름이 없으면 회색 칩으로 표시되며, 하단 검증 리포트가 자동으로 잡아냅니다.
