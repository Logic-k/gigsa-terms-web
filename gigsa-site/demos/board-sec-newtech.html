시험에 반드시 나오는 암호화 알고리즘의 분류, 디지털 저작권 관리(DRM), 클라우드 컴퓨팅과 최신 네트워크 기술을 정복하세요.

1️⃣ 암호화 기법 (Cryptography)

암호화와 복호화에 사용하는 키(Key)가 같은지, 다른지에 따라 분류합니다.

🔑

대칭키 (Symmetric)

비밀키 암호화 기법

암호화 키와 복호화 키가 동일한 방식입니다.
송수신자가 같은 키를 몰래 공유해야 합니다.

  • 장점 속도가 빠르다
  • 단점 키 배송이 어렵고 키가 많이 필요함
대표 알고리즘 (필수 암기) DES, AES, SEED, ARIA, IDEA
🔓🔐

비대칭키 (Asymmetric)

공개키 암호화 기법

암호화 키(공개)와 복호화 키(개인)가 서로 다른 방식입니다.
모두에게 암호화 키를 공개해버립니다.

  • 장점 키 분배가 쉽고 안전함 (관리 키 수 적음)
  • 단점 수학적 연산이 복잡해 속도가 매우 느림
대표 알고리즘 (필수 암기) RSA, ECC (타원 곡선), DSA
⚙️

해시 (Hash)

단방향 (일방향) 암호화

임의의 길이의 데이터를 고정된 길이의 데이터로 변환합니다. 암호화만 가능하고 복호화는 불가능합니다.

  • 목적 무결성 검증 (데이터가 변조되지 않음)
  • 용도 패스워드 저장, 블록체인 등
대표 알고리즘 (필수 암기) SHA (SHA-256 등), MD5, HAS-160

2️⃣ 디지털 저작권 관리 (DRM)

디지털 콘텐츠의 불법 복제와 유포를 막고, 저작권자의 권리와 이익을 보호하는 기술과 서비스입니다.

DRM 구성 요소 아키텍처

🎬 콘텐츠 제공자 (Contents Provider)
콘텐츠를 제작하고 제공
➔
⬇
📦 콘텐츠 분배자 / 패키저
콘텐츠를 암호화하여 보안 컨테이너로 패키징
➔
⬇
👤 콘텐츠 소비자
DRM 컨트롤러를 통해 라이선스 확인 후 사용
⚖️ 클리어링 하우스 (Clearing House)
라이선스 발급, 결제 관리,
권한 정책 통제 (핵심 관리소)

💡 워터마킹 (Watermarking)

디지털 파일에 원소유자의 저작권 정보를 눈에 띄지 않게(혹은 띄게) 삽입하는 기술입니다. 불법 복제 추적에 사용됩니다.

💡 DRM 컨트롤러 (Controller)

사용자의 기기(PC, 스마트폰)에서 작동하며, 콘텐츠의 이용 권한을 통제하고 클리어링 하우스와 통신하는 프로그램입니다.

3️⃣ 클라우드 서비스 & IT 신기술 용어

서비스 제공 수준에 따른 클라우드 분류와 자주 출제되는 최신 기술 용어입니다.

클라우드 서비스 분류 (XaaS)

SaaS Software as a Service
완제품 소프트웨어 제공
ex) 구글 드라이브, 네이버 MYBOX
PaaS Platform as a Service
개발 환경/플랫폼 제공
ex) AWS Elastic Beanstalk, Heroku
IaaS Infrastructure as a Service
서버, 스토리지 등 인프라 제공
ex) AWS EC2, Azure Virtual Machines

필수 암기 신기술 용어집

🐘

하둡 (Hadoop)

대량의 데이터를 적은 비용으로 저장하고 처리할 수 있는 오픈 소스 자바 소프트웨어 프레임워크. 핵심 요소는 분산 파일 시스템(HDFS)과 맵리듀스(MapReduce)입니다.

🖧

SDN (소프트웨어 정의 네트워킹)

네트워크 장비의 제어부(Control Plane)와 전송부(Data Plane)를 분리하여, 소프트웨어로 네트워크를 중앙에서 제어하고 관리하는 기술입니다. (OpenFlow 프로토콜 활용)

📱

BYOD & MDM

BYOD: 개인 소유 기기를 업무에 활용하는 환경.
MDM(모바일 기기 관리): 이 환경에서 기기를 원격 제어, 보안 정책 적용, 데이터 삭제(Wipe) 등을 수행하는 보안 솔루션입니다.

🖥️

NFV (네트워크 기능 가상화)

방화벽, 라우터 등의 하드웨어 기반 네트워크 장비 기능을 소프트웨어 형태로 가상화하여 범용 서버에서 실행하는 기술입니다. (SDN과 찰떡궁합)
