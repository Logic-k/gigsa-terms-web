정규화, 어렵게 외우지 말고
인터랙티브하게 이해하세요

정규화는 비대해진 테이블을 의미 있는 단위로 쪼개어 데이터의 중복을 제거하고 안정성을 확보하는 과정입니다. 정보처리기사 핵심 요소를 직접 체험해보세요.

⚠️ 왜 정규화를 해야 할까요? (이상 현상)

정규화가 되지 않은 '뚱뚱한 테이블'에서 발생하는 치명적인 3가지 문제점을 클릭해서 확인해보세요.

🔄

수정 이상 (Update)

데이터 일부만 수정했을 때 데이터 간 불일치가 발생하는 현상

➕

삽입 이상 (Insertion)

원치 않는 데이터를 함께 넣지 않으면 삽입이 불가능한 현상

🗑️

삭제 이상 (Deletion)

데이터 하나를 지웠는데 필요한 정보까지 다 사라지는 현상

anomaly_simulator.log
위의 카드 중 하나를 클릭하여 이상 현상 시나리오를 시뮬레이션 하세요.
