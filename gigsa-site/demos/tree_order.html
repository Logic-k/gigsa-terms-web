🧮 수식 트리와 표기법 변환

트리의 순회 방식을 수식(Expression)에 적용하면, 컴퓨터가 계산하기 쉬운 표기법으로 변환됩니다.
상단의 '수식 트리'를 선택하고 순회 버튼을 눌러 시뮬레이션 해보세요.

중위 표기법
Infix Notation

중위 순회
A + B * C - D

우리가 일상적으로 사용하는 방식입니다. 연산자가 피연산자 가운데(In) 위치합니다. 사람이 읽기는 편하지만, 괄호와 연산자 우선순위 때문에 컴퓨터가 처리하기는 까다롭습니다.

전위 표기법
Prefix Notation

전위 순회
* + A B - C D

연산자가 피연산자 앞(Pre)에 위치합니다. 스택(Stack)을 이용하여 괄호 없이도 우선순위에 맞게 컴퓨터가 빠르게 계산할 수 있도록 고안되었습니다.

후위 표기법
Postfix Notation

후위 순회
A B + C D - *

연산자가 피연산자 뒤(Post)에 위치합니다. 컴퓨터가 수식을 처리할 때 가장 많이 사용하는 방식이며, 정보처리기사 시험에 단골로 출제되는 핵심 표기법입니다.

💡 시험 꿀팁: 수식 트리에서 피연산자(A, B, C 등)는 무조건 '단말 노드(잎새)'에 위치하고, 연산자(+, -, * 등)는 무조건 '부모 노드(가지)'에 위치합니다!

순회 알고리즘
완벽 정리 보드

  • 1

    재귀적 속성

    모든 순회는 재귀적입니다. 하나의 서브트리에서 적용된 규칙은 전체 트리에서도 동일하게 반복됩니다.

  • 2

    전위의 특징

    결과값의 맨 첫 번째 노드는 항상 전체 트리의 루트(Root) 노드입니다.

  • 3

    중위의 특징

    이진 탐색 트리(BST)를 중위 순회하면 오름차순으로 정렬된 결과를 얻을 수 있습니다.

기출 암기 공식

PRE Root-L-R
IN L-Root-R
POST L-R-Root

※ 화살표 방향으로만 움직인다고 생각하지 말고, "언제 부모를 처리하는가"에 집중하세요.
