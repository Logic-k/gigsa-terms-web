🖥️

SaaS (소프트웨어 제공)

사용자가 별도의 설치 없이 인터넷을 통해 애플리케이션(소프트웨어)을 바로 사용하는 서비스입니다.
예: 구글 워크스페이스, 네이버 MYBOX, 넷플릭스

PaaS (플랫폼 제공)

개발자가 소프트웨어를 개발, 테스트, 배포할 수 있는 환경(운영체제, DB 등 플랫폼)을 제공하는 서비스입니다.
예: AWS Elastic Beanstalk, Heroku

IaaS (인프라 제공)

서버, 스토리지, 네트워크 등 가장 기초적인 컴퓨팅 자원(하드웨어 인프라)을 가상화하여 제공합니다. 사용자가 OS부터 직접 설치해야 합니다.
예: AWS EC2, Microsoft Azure VM

🐘 빅데이터와 하둡(Hadoop)

대규모 데이터를 분산 처리하는 핵심 오픈소스 프레임워크와 주요 기술입니다.

하둡 (Hadoop) 핵심 구성

일반 PC급 컴퓨터들로 가상화된 대형 클러스터를 구성하여 방대한 데이터를 분산 저장하고 처리하는 자바(Java) 기반 프레임워크입니다.

분산 저장 기술

HDFS

(Hadoop Distributed File System)
대용량 파일을 여러 서버에 쪼개어 저장하고 다중 복제하여 신뢰성을 확보하는 파일 시스템.

분산 처리 기술

맵리듀스 (MapReduce)

데이터를 필터링/분류하는 Map 작업과, 그 결과를 요약/합산하는 Reduce 작업으로 나누어 병렬 처리하는 프로그래밍 모델.

관련 데이터 기술

데이터 마이닝 (Data Mining)

대규모 데이터 세트 안에서 숨겨진 패턴, 관계, 규칙을 찾아내어 예측 가능한 유용한 정보로 변환하는 기술입니다.

텍스트 마이닝 (Text Mining)

반정형/비정형 텍스트 데이터(뉴스, SNS 글 등)에서 자연어 처리(NLP) 기술을 활용해 유용한 정보를 추출하는 기법입니다.

타이포스쿼팅 (Typosquatting)

💡 빅데이터와 직접적 관련은 없지만 자주 나오는 보안 용어

사용자가 인터넷 주소를 칠 때 오타를 내기 쉬운 점을 노려, 유명 사이트와 철자가 비슷한 도메인을 미리 등록해 두고 해킹/광고에 이용하는 수법 (URL 하이재킹).

🖧 차세대 네트워크: SDN vs NFV

네트워크를 하드웨어 중심에서 소프트웨어 중심으로 혁신하는 두 가지 핵심 기술입니다.

🧠

SDN

Software-Defined Networking

네트워크 장비(라우터, 스위치)에서 '경로를 결정하는 두뇌(제어부, Control Plane)'와 '데이터를 전달하는 손발(전송부, Data Plane)'을 분리하는 기술입니다.

⭐ 핵심 포인트
  • 제어부와 전송부의 분리
  • 소프트웨어를 통한 중앙 집중식 네트워크 제어
  • 대표 프로토콜: OpenFlow (오픈플로우)
💻

NFV

Network Functions Virtualization

방화벽, 라우터 등 기존의 전용 하드웨어 장비가 하던 네트워크 '기능'들을 소프트웨어 형태로 가상화(Virtualization)하여, 일반 범용 서버(x86)에서 실행하는 기술입니다.

⭐ 핵심 포인트
  • 하드웨어 중심 ➔ 소프트웨어(가상 머신) 중심으로 전환
  • 특수 장비 구매 비용 절감 및 유연성 증가
  • SDN과 함께 사용되어 시너지 효과를 냄

📚 정보처리기사 단골 신기술 용어

객관식/단답형 실기 문제로 빈출되는 최신 IT 트렌드 용어 총정리입니다.

🧩

MSA (마이크로서비스 아키텍처)

거대한 하나의 애플리케이션(Monolithic)을 독립적으로 배포 가능한 작고 여러 개의 서비스 단위로 쪼개어 개발하는 아키텍처입니다.

👯

디지털 트윈 (Digital Twin)

현실 세계의 물리적 사물이나 시스템을 가상 세계(컴퓨터)에 똑같이 복제하여 시뮬레이션함으로써 결과를 예측하는 기술입니다.

🐳

도커 (Docker) / 컨테이너

애플리케이션과 그 실행에 필요한 라이브러리, 환경 등을 패키지로 묶어(컨테이너) 격리된 환경에서 실행하는 가상화 플랫폼입니다.

⛓️

블록체인 (Blockchain)

데이터를 블록에 담아 체인 형태로 연결하고, 수많은 컴퓨터에 동시에 분산 저장하여 위/변조를 막는 P2P 분산 원장 기술입니다.

📱

BYOD & MDM

BYOD: 개인 소유 스마트기기를 회사 업무에 활용하는 환경.
MDM: 이를 안전하게 통제(데이터 삭제, 보안설정)하는 모바일 기기 관리 솔루션.

📡

엣지 컴퓨팅 (Edge Computing)

중앙 클라우드 서버까지 데이터를 보내지 않고, 데이터가 발생하는 주변(Edge) 기기 근처에서 데이터를 즉시 처리하여 지연 시간을 줄이는 기술입니다.
