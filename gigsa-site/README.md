# 정보처리기사 용어사전 — 배포 패키지

용어 **1,008개** · 실무 예시 **1,008개** · 도식 **464개** · 챕터 **69개** · 혼동 링크 **2,473건**

---

## 1. 배포하기 (계정 연동 · CLI 설치 불필요)

### 방법 A — Netlify Drop (가장 빠름, 설치할 것 없음)

1. 브라우저에서 **https://app.netlify.com/drop** 접속
2. 이 `gigsa-site` **폴더를 그대로 끌어다 놓기**
3. 30초 안에 `https://무작위이름.netlify.app` 주소가 나옵니다
4. 그 주소를 폰으로 열면 끝

> 로그인하지 않으면 임시 사이트이고, 무료 계정으로 로그인하면 영구 보관 + 주소 변경이 가능합니다.

### 방법 B — Vercel 웹에서 끌어다 놓기

1. **https://vercel.com/new** 접속 후 로그인 (GitHub·구글 계정으로 가능)
2. 아래쪽 **Deploy without Git / Browse** 영역에 `gigsa-site` 폴더를 끌어다 놓기
   (드래그가 안 되면 `gigsa-site.zip` 을 올려도 됩니다)
3. **Deploy** → `https://프로젝트이름.vercel.app` 주소 발급

### 방법 C — Vercel CLI (`deploy-vercel.bat` 더블클릭)

폴더에 든 **`deploy-vercel.bat`** 을 더블클릭하면 됩니다. **Node.js 가 설치되어 있어야** 동작합니다(없으면 https://nodejs.org 에서 LTS 설치).

실행하면 두 가지를 물어봅니다.

- **1번 — 브라우저 로그인 (권장).** 토큰을 입력하지 않고 브라우저 인증으로 배포합니다.
- **2번 — 토큰 입력.** 토큰을 쓰고 싶을 때만 고르세요.

> **토큰을 쓸 때 주의.** Vercel 토큰은 계정 전체의 배포·삭제 권한을 가집니다. 채팅·메모·파일에 붙여넣은 토큰은 **쓰고 나서 반드시 폐기**하세요. Vercel → Settings → Tokens → Delete. 그래서 이 스크립트는 토큰을 파일에 저장하지 않고 실행할 때마다 물어봅니다.

### 방법 D — Cloudflare Pages

1. **https://pages.cloudflare.com** → Create a project → **Upload assets**
2. 폴더 또는 zip 업로드 → 배포

> 네 곳 모두 무료 요금제로 충분하고, HTTPS 가 자동 적용됩니다.
> **HTTPS 가 있어야 오프라인 캐시(서비스 워커)가 동작합니다.**

## 2. 폰에 설치하기 (홈 화면 추가 + 오프라인)

배포된 주소를 폰에서 열고 **한 번 끝까지 스크롤**해 두면 파일이 캐시됩니다. 그 뒤로는 비행기 모드에서도 열립니다.

| 기기 | 방법 |
|---|---|
| iPhone · iPad (Safari) | 하단 **공유 버튼** → **홈 화면에 추가** |
| Android (Chrome) | 우측 상단 **⋮** → **앱 설치** 또는 **홈 화면에 추가** |
| 데스크톱 Chrome·Edge | 주소창 오른쪽 **설치 아이콘** |

Android 에서는 페이지 안에 **홈 화면에 추가하고 오프라인으로 쓰기** 버튼이 직접 나타납니다.

## 4. 내용 추가·수정하기

### 용어 추가 — `data.js`

챕터 배열 안에 6칸 배열을 넣습니다.

```js
[ "용어명",
  "영문 / 풀네임",
  "한 줄 정의",
  "상세 설명",
  "혼동용어1|혼동용어2",     // 다른 용어명과 정확히 일치해야 링크가 걸림
  "출제 형태" ]
```

### 예시 추가·수정 — `ex-data-*.js`

```js
"용어명": ["실무 사례 한 줄", "암기 고리 한 줄"],
```

`사례` 는 어디서 실제로 쓰이는지, `고리` 는 단어나 일상에 붙여 기억하는 장치입니다. 검색은 예시 본문까지 걸리므로 `우체통` 으로 검색하면 MOM 이 나옵니다.

### 도식 추가 — `dia-data-*.js`

```js
"용어명": "타입:본문",
```

사용 가능한 16종:

| 타입 | 문법 | 쓰임 |
|---|---|---|
| `stack` | `stack:위\|중간\|아래` | 계층 구조 (OSI 7계층) |
| `rank` | `rank:약함>강함::A\|B\|C` | 순위 (결합도·응집도) |
| `chain` | `chain:A\|B\|C` | 순서 흐름 (요구공학 5단계) |
| `split` | `split:제목;;항목;항목//제목;;항목` | 대비 (TCP vs UDP) |
| `pair` | `pair:왼쪽;설명//오른쪽;설명` | 양방향 대응 (ARP/RARP) |
| `bits` | `bits:라벨=비중\|라벨=비중` | 비트·주소 구조 |
| `grid` | `grid:헤더1,헤더2\|\|a,b\|\|c,d` | 표 |
| `pyramid` | `pyramid:위\|아래` | 단계 피라미드 (CMMI) |
| `bar` | `bar:라벨=값\|라벨=값` | 크기 비교 |
| `nest` | `nest:겉>중간>안` | 포함 관계 (캡슐화) |
| `ox` | `ox:문장=O;메모\|문장=X;메모` | O/X 판별 |
| `code` | `code:줄1\\n줄2` | 코드·수식 |
| `tree` | `tree:부모>자식\|부모>자식` | 트리 (키 관계) |
| `flow` | `flow:A>B:라벨\|B>C:라벨` | 상태 전이 |
| `cycle` | `cycle:A\|B\|C` | 반복 사이클 |
| `topo` | `topo:star` (star·ring·bus·mesh·tree·hub) | 네트워크 토폴로지 |

앞의 12종은 HTML/CSS 라 화면 폭에 맞춰 다시 배치되고, 뒤의 4종은 SVG 라 확대해도 깨지지 않습니다.

### 수정 후 재배포

같은 방법으로 폴더를 다시 끌어다 놓으면 됩니다.
**단, `sw.js` 첫 줄의 `CACHE` 버전(현재 `gigsa-v2`)을 올려야** 기존 방문자의 캐시가 갱신됩니다. 이걸 잊으면 폰에서 옛 내용이 계속 보입니다.

## 5. 로컬에서 먼저 확인하려면

`index.html` 을 그냥 더블클릭해도 열립니다. 다만 `file://` 에서는 서비스 워커가 등록되지 않아 오프라인 캐시만 동작하지 않습니다. 나머지 기능은 모두 정상입니다.

로컬 서버로 완전히 확인하려면 폴더에서:

```
python3 -m http.server 8000
```

후 `http://localhost:8000` 접속. (localhost 는 HTTPS 예외로 서비스 워커가 동작합니다.)
