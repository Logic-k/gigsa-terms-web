챕터 목차

헷갈리는 용어를 그림과 짝으로 잡는 사전

용어를 누르면 실무 사례 · 암기 고리 · 상세 설명 · 도식 · 혼동 용어 · 출제 형태가 열립니다. 예시 는 전 용어에, 그림 은 도식이 있는 용어에 붙습니다.

혼동 용어 칩을 누르면 그 용어로 바로 이동합니다. 왼쪽 ? 버튼으로 모르는 용어를 표시하고 상단 모름으로 모아 보세요.

모바일에서 쓰는 방법

  • 홈 화면에 추가 — iPhone Safari 는 공유 버튼 → 홈 화면에 추가, Android Chrome 은 메뉴 → 앱 설치. 한 번 열어 두면 지하철·버스에서 네트워크 없이도 열립니다.
  • 왼쪽 위 ☰ 로 챕터 목차, 오른쪽 위 가 로 전체 색인, ◐ 로 밝은/어두운 테마를 바꿉니다.
  • 도식은 화면 폭에 맞춰 세로로 접힙니다. 표는 좌우로 밀어 보세요.

예시

용어마다 실무 사례(어디서 실제로 쓰이는지)와 암기 고리(단어나 일상에 붙여 기억하는 장치) 두 줄이 붙어 있습니다. 사례는 실제 사용 맥락을 기준으로 작성했고, 도구 현황·보안 사고처럼 사실이 낡을 수 있는 항목은 웹으로 확인했습니다. 다만 개별 제품의 최신 버전이나 점유율은 바뀔 수 있습니다.

도식 유형

계층(stack) · 순위(rank) · 흐름(chain) · 대비(split) · 양방향(pair) · 비트 구조(bits) · 표(grid) · 피라미드 · 크기 비교(bar) · 포함(nest) · O/X 판별 · 코드/수식 · 트리 · 상태 전이(flow) · 사이클 · 토폴로지 — 총 16종. 앞의 12종은 HTML/CSS 라 화면 폭에 따라 다시 배치되고, 뒤의 4종은 SVG 라 확대해도 깨지지 않습니다.

확장 방법

data.js 의 DICT 에 용어를, dia-data-*.js 에 도식을, ex-data-*.js 에 "용어명":["사례","고리"] 형식으로 예시를 추가하면 됩니다. 도식이 없어도 용어는 정상 표시됩니다.

마인드맵은 각 챕터의 상세설명을 분석해 포함 관계를 자동으로 계층화합니다(예: 미들웨어 → WAS·RPC·MOM·TP-Monitor·ORB). 별도 데이터 없이 용어만 늘리면 트리도 함께 자랍니다.

인터랙티브 자료(실습)는 demos/ 폴더에 HTML 한 장을 넣고 demos.js 의 DEMOS 에 {id,title,icon,file,desc,subj,terms} 한 줄을 추가하면 됩니다. terms 에 적은 용어의 사전 카드·마인드맵에 ▶ 인터랙티브 버튼이 자동으로 붙습니다.
